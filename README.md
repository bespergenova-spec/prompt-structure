# Планер задач

Небольшое окно на рабочем столе со списком открытых задач. Один файл `index.html`, работает без интернета и без установки программ (используется Edge или Chrome в режиме «приложение»: окно без вкладок и адресной строки).

## Запуск
Дважды щёлкните `install-shortcut.bat` — на рабочем столе появится ярлык **«Планер задач»**. Дальше запускайте планер им.
Чтобы планер открывался вместе с Windows: `install-shortcut.bat -Autostart`.
Размер и положение окна запоминаются.

## Как пользоваться
- **Новая задача** — впишите текст и Enter. Срок и время можно написать словами: «завтра», «до 15.11», «25 ноября», «в 14:30» — они подставятся сами.
- **Виды:** работа, здоровье, семья, друзья, дом. Фильтр — кнопки сверху.
- **Дата** в формате `10.11.2026` (можно `10.11` — год подставится сам, или выбрать в календаре 📅). **Время** `чч:мм` необязательно.
- **Статусы:** открыта / закрыта. Галочка закрывает задачу, она уходит в раздел «Закрытые» (там можно открыть снова). Название, вид, дату и время можно править прямо в строке.
- **Задачи из протокола** — кнопка «Из протокола». Перетащите файл Word (`.docx`) или вставьте текст. Планер ищет вас по имени (по умолчанию «Еспергенова Балнур»; его можно поменять в окне): фамилия, имя, любое сочетание, инициалы (`Еспергенова Б.`, `Б.Е.`), любые падежи. Строки таблиц тоже учитываются, срок и время из строки подставляются. Перед добавлением вы видите список найденного, можно снять лишние галочки и поправить. Задачи попадают в «Работа».
- **Копия данных** — кнопка `⋯`. Данные хранятся в браузере (Edge/Chrome), поэтому иногда сохраняйте копию; её можно загрузить обратно.
