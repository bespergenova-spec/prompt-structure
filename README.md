# prompt-structure

Репозиторий показывает, как изменился результат работы Claude, когда тот же запрос переписали в более структурированный промпт (задача → контекст → формат → пример).

## Задача: планер задач на компьютере

### Промпт 1

```
сделай планер для компьютера. Цель - отслеживание задач.
Нужно вбить инфо по наименованию задачи, виды задач (работа, здоровье, семья, друзья, дом, другое), сроки, статус (открыта/ закрыта). Добавь возможность подгрузки протоколов, откуда можно будет вычленить именно мои задачи и добавлять в вид задач "работа". Пусть будет планер удобный, не хочу тратить много времени на его ведение
```

### Промпт 2

```
задача: создать планер задач на локальном компьютере
контекст: задачи должны быть разных видов: работа, здоровье, семья, друзья, дом. Хочу также чтобы была возможность заливать протоколы в ворде, откуда будут потягиваться мои рабочие задачи (ориентируйся на мое имя Еспергенова Балнур, возможно только имя или фамилия, или иное сочетание, или инициалы). Должны быть статусы: открыта и закрыта. Указано дата по примеру 10.11.2026, а также возможность указать время (но необязательно)
формат: небольшое окно отображающееся на рабочем столе со списком текущих открытых задач
пример: любые удобные, юзерфрендли приложения
```

### Что изменилось в ответе

| | Ответ на промпт 1 (коммит `b278804`) | Ответ на промпт 2 (коммит `a23c20a`) |
|---|---|---|
| **Как выглядит и запускается** | Обычная страница `index.html` с боковой панелью; открывается во вкладке браузера | Компактное окно 400×680 без вкладок и адресной строки; ярлык «Планер задач» на рабочем столе (`install-shortcut.bat`), по желанию автозапуск с Windows |
| **Виды задач** | Шесть: работа, здоровье, семья, друзья, дом, **другое** | Пять, как в промпте: работа, здоровье, семья, друзья, дом |
| **Срок** | Стандартное поле даты браузера, формат зависит от настроек | Формат `10.11.2026`; можно ввести `10.11` (год подставится) или выбрать в календаре |
| **Время** | Нет | Необязательное `чч:мм`; распознаётся и из текста («завтра в 9:30», «до 15.11 в 14:00») |
| **Статусы** | Открыта / закрыта, вкладки «Открытые», «Закрытые», «Все» | Открыта / закрыта; в окне только открытые, закрытые свёрнуты внизу |
| **Протоколы** | `.docx`, `.txt`, `.md`; фамилию нужно было вводить самому, поиск по фамилии | Основной сценарий — Word (`.docx`); имя «Еспергенова Балнур» уже вписано; ищутся фамилия, имя, любое сочетание, инициалы (`Еспергенова Б.`, `Б.Е.`) и падежи; из строки берутся срок и время |
| **Главный экран** | Все задачи с фильтрами и поиском | Список текущих открытых задач по срокам: просрочено, сегодня, 7 дней, позже, без срока |

Общее в обоих ответах: данные хранятся в браузере, есть сохранение и загрузка копии, перед добавлением задач из протокола показывается список найденного для проверки, найденные задачи попадают в «Работа».

Главное отличие: в промпте 1 не было ни формата результата, ни примера, поэтому получилась обычная веб-страница. Промпт 2 задал формат («небольшое окно на рабочем столе»), точный вид даты, необязательное время и имя для поиска. Ответ стал ближе к тому, что нужно: окно вместо страницы, время в задачах, поиск по имени в любых формах.

## Как пользоваться планером (последняя версия)

1. Дважды щёлкните `install-shortcut.bat` — на рабочем столе появится ярлык «Планер задач». Чтобы планер открывался вместе с Windows: `install-shortcut.bat -Autostart`.
2. **Новая задача** — текст и Enter. Срок и время можно написать словами: «завтра», «до 15.11», «25 ноября», «в 14:30».
3. **Закрыть задачу** — галочка слева. Название, вид, дату и время можно править прямо в строке.
4. **Из протокола** — перетащите файл Word (`.docx`) или вставьте текст, проверьте найденные задачи и добавьте. Имя для поиска можно поменять в этом же окне.
5. **Копия данных** — кнопка `⋯`. Данные хранятся в браузере (Edge или Chrome), поэтому иногда сохраняйте копию.
