# Планер задач

Один файл `index.html` — откройте его двойным кликом в Chrome/Edge. Ничего устанавливать не нужно, работает без интернета.

## Как пользоваться
- **Новая задача** — впишите текст и нажмите Enter. Срок можно написать словами: «завтра», «до 15.11», «25 ноября» — он подставится сам.
- **Закрыть задачу** — галочка слева. Название, вид и срок правятся прямо в строке.
- **Фильтры** — виды слева (работа, здоровье, семья, друзья, дом, другое), вкладки «Открытые / Закрытые / Все», поиск.
- **Задачи из протокола** — кнопка слева внизу. Один раз укажите фамилию, затем перетащите файл (`.docx`, `.txt`, `.md`) или вставьте текст. Планер найдёт строки и строки таблиц с вашей фамилией, предложит список — снимите лишние галочки, поправьте текст и добавьте. Задачи попадут в вид «Работа». Для `.pdf` скопируйте текст и вставьте в поле.
- **Копия данных** — данные лежат в браузере, поэтому иногда нажимайте «Сохранить копию» (файл `.json`), её же можно загрузить обратно.
